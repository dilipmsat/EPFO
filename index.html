How to download the MIS Claims Report from the MIS 3.0 portal.
  1. Go to https://mis.epfindia.gov.in/misnew/ and log in with your credentials (same as the HR portal).
  2. Search for [Claims Pending Report] in the search bar and click on it.
  3. Submit without changing any details.
  4. Click on the Total Pending number, then in the pop-up window click Download File.
  5. Upload the downloaded file to this page.
  6. Click on Continue to Configure Thresholds.
  7. Click on Build Dashboard (change as required if needed, then click).
Expected columns: OFFICE ID · CLAIM ID · RECEIPT DATE · MEMBER ID · EXMEMPTION STATUS · FORM TYPE · ON LINE · MODE · ACC GROUP ID · ACC TASK ID · STATUS · PENDING DAYS · UAN · DEATH CASE · REMARKS
