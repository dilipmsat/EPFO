Need help? How to use this website

What this is

A dashboard that turns the EPFO MIS 3 – Claims Pending Report into ageing analysis, a comprehensive pendency matrix, per-Task/Group breakdowns, and ready-to-print PDF/Excel reports. It runs entirely in your browser — your MIS data is not sent anywhere unless you deliberately use "Upload MIS & Publish" to share it with colleagues at your own office.

Which of the two options should I use?

  • Upload the MIS 3 Claims Pending Report — use this if you have today's MIS file and are the person responsible for putting it up for the office (EDP Section, or anyone with MIS access). You will set a PIN that others can use to view the same dashboard without uploading anything themselves.
  • Access Existing Dashboard — use this if someone else at your office has already uploaded today's MIS and given you the PIN. Enter your 3-digit Office Code and that PIN to see the same dashboard, reports and analysis instantly.

Only one of the two is needed — never both.

Step by step, after uploading or accessing

  1. Configure Thresholds — confirm the RO name and set the ageing-day thresholds used to flag overdue claims, then click Build Dashboard.
  2. Dashboard — KPI cards, ageing charts, and the Comprehensive Pendency Matrix. Click any number to see the underlying claims.
  3. Custom Dashboard — pick any single Group ID or Task ID for a focused breakdown.
  4. Generate Reports — build PDF/Excel reports for specific ageing thresholds, sections, or the whole office.
  5. Performance Reports and Additional Reports — settlement performance and DSC/e-Sign pendency, from separate MIS exports.

About the PIN

The PIN is set fresh each time the MIS is published and is only meant to keep the dashboard within your own office — share it with whoever at your office needs to view it. It is not stored or transmitted in plain text.

Still stuck?

How to Create Performance Reports

Download the claims periodicity claims report (Performance Report) from MIS.

  1. Go to https://mis.epfindia.gov.in/misnew/ and log in with your credentials (same as the HR portal).
  2. Search for [Periodicity of Claims] in the search bar and click on it.
  3. In the Periodicity of Claims tab, click on the Submit button, then the RECEIPT Number.
  4. A pop-up window will appear — click on “here” [You can View (Status)/Download your requested Data/File from here].
  5. Wait a few minutes; the file (report) will appear in the Generated Files tab.
  6. Click the Download button once the file has appeared.
  7. Upload the downloaded file to this page.
